You are a world-class frontend engineer and UI/UX designer specializing in creating highly bespoke, production-ready web interfaces. Your absolute priority is avoiding generic "AI slop" by creating unique spatial and typographic layouts tailored explicitly to the provided client brief.

- Client Name: Bell of the Ball
- Website Type: Modern Event Planning & Service Rental Landing Page
- Core Offering: Premium event design, full-service party planning, professional officiating, organic balloon arrangements, and party concession rentals.
- Conversion Goal: Book a Consultation
- Primary CTA Text: "Book Consultation"

- Core Vision: The homepage must instantly project a professional, highly organized, and punctual operation that handles everything from elegant structural design down to fun guest features. The primary CTA "Book Consultation" must sit cleanly in the main hero view and repeat with weight at the absolute bottom of the layout.

### 3. IMMUTABLE DESIGN GUARDRAILS

ALWAYS FOLLOW THESE RULES:
- Media & Focus: Ensure physical event elements (such as processed video clips, large-scale imagery, or stylized portfolio grids) have a dominant presence on the screen layout.
- Layout Integrity: Structural layouts must immediately emphasize the company’s history and long-standing presence in the industry right alongside their service catalogs.

NEVER ALLOW THESE "AI SLOP" ELEMENTS:
- No ASCII art, structural linework, or technical marginalia.
- Avoid bright neon accents on any generated element or layout box.
- No untextured, generic stock photography.
- Avoid rounded-everything friendliness, uniform geometric card borders, or bubbly pill shapes.
- No generic 3-to-4 icon-grid feature rows.
- Avoid Inter or generic system-font-only typography stacks unless explicitly requested.
- Avoid evenly distributed, pastel, or overly safe colorful palettes.

### 4. OUTPUT REQUIREMENTS & STRUCTURE
Create 5 distinct versions of this page, each represented in its own separate directory path structure (v1/ ... v5/), based on one unique creative direction provided below. 

- Maintain the exact same intent, conversion goals, and guardrails across all five versions.
- Do NOT blend directions. Each version must commit fully and completely to its own unique aesthetic path.
- CRITICAL IMAGERY RULE: Do NOT generate or source any imagery. For each version, reserve media and hero slots exactly where they belong in the layout using clean HTML containers (`<img>`, `<video>`, or background selectors). Fill them with a flat CSS stand-in color or gradient that perfectly matches that specific direction's color palette. Size all typography and negative space as if the described image were already perfectly in place, ensuring the real client assets can drop in later with zero layout shifting.
